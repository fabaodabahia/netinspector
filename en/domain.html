🔍 What is Domain Analysis?

Domain analysis is a technical audit examining all public facets of a website or server. It ranges from DNS routing to SSL/TLS encryption, mail exchange records, and HTTP security headers. é um procedimento técnico de auditoria que investiga todos os aspectos públicos da presença digital de um site ou servidor na internet. Ela abrange desde o roteamento básico de tráfego (DNS) até camadas críticas de criptografia (SSL/TLS), políticas de correio eletrônico (SPF, DKIM, DMARC) e cabeçalhos de segurança que protegem os visitantes contra ataques virtuais.

🌐 How to check website DNS records?

The Domain Name System (DNS) translates human-friendly hostnames into machine-readable IP addresses. Our tool uses DNS-over-HTTPS (DoH) to inspect essential records (A, AAAA, MX, NS, TXT, CNAME). é a agenda telefônica da internet, convertendo nomes de domínios memorizáveis (como google.com) em endereços numéricos IP legíveis por máquinas. Nossa ferramenta consulta resoluções autoritativas via DNS-over-HTTPS (DoH) para examinar múltiplos tipos de registros essenciais:

  • Registros A e AAAA: Mapeiam o domínio para os servidores IPv4 e IPv6 de hospedagem.
  • Registros MX (Mail Exchange): Indicam os servidores responsáveis por receber e-mails no domínio.
  • Registros NS (Name Server): Identificam quais servidores autoritativos hospedam as zonas DNS do site (ex: Cloudflare, Route 53).
  • Registros TXT: Guardam chaves de verificação de propriedade e regras vitais de combate a spam e phishing, como SPF e DMARC.
  • Registros CNAME: Criam pseudônimos ou redirecionamentos canônicos para outros nomes de host.

🔐 Why verify SSL/TLS certificates?

HTTPS encrypts data between user browsers and web servers. Auditing certificates confirms validity dates, certificate authority chains, and modern protocol support (TLS 1.2 / TLS 1.3). garante que toda a comunicação entre o navegador do usuário e o servidor web permaneça criptografada, impedindo interceptações por terceiros (ataques Man-in-the-Middle). Auditar o certificado SSL/TLS permite atestar:

1) A validade temporal do certificado, prevenindo erros de expiração que bloqueiam os visitantes com avisos de segurança alarmantes; 2) A cadeia de confiança (Certificate Authority), assegurando que o certificado foi emitido por uma autoridade reconhecida mundialmente; e 3) O suporte a versões criptográficas modernas, como TLS 1.2 e TLS 1.3, isolando cifras obsoletas suscetíveis a vulnerabilidades históricas (como POODLE ou BEAST).

📋 What is Whois and why is it useful?

Whois queries public domain registrar databases to reveal registration dates, renewal timestamps, and expiration deadlines. é um protocolo padronizado que permite consultar os bancos de dados públicos dos registradores de domínios (como Registro.br, Verisign e ICANN). Através dele, é possível descobrir a data em que o domínio foi registrado pela primeira vez, sua última data de renovação e a data exata de expiração.

Essas informações são cruciais para monitorar a antiguidade de um site (domínios mais antigos transmitem maior autoridade para motores de busca), conferir o status do domínio e planejar a renovação contratual antes do congelamento ou leilão do domínio.
